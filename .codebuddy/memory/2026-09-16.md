## 📊 Phase 0 首跑：rhythm_profile.py 落地与画像结果（2026-09-16，未提交）
- **产出 `scripts/rhythm_profile.py`**（~600 行，纯只读 + numpy 手写统计）：
  - 模块 `data-check`/`episode`/`causality`/`lag`，`--theta-scale`/`--json` 可选
  - 手写 OLS+Newey-West HAC / winsorize / ACF+Ljung-Box（无 scipy/statsmodels 依赖）
  - 口径：F_t=全池 SUM(main_net)（**库内单位=元，加载即 /1e8 转亿**——曾因元/小数 12 个数量级尺度差把 X'X 弄病态、t 值算崩，亿口径根治）；E_t 剥离 β 用 winsorize 回归、E 用原始值；C_t 燃烧 30 日；zigzag θ=θ_scale×σ(E)；d1=起点极值确认日（前向无前视）
- **P0.D 数据可得性答案**：mainflow_history **127 交易日**（03-16~09-15，715 只）→ A/B/C 立即可跑但 n 小；mainforce_state 标签**仅 6 天**（09-04~09-15）→ 宽度序列现有历史不可用，需重算器用 backtest_prices（3 年、714 只个股）回算筹码标签扩样。
- **★ Phase 0 画像核心发现（127 日，初判非正式 Gate）**：
  1. **B0：E 接近白噪声**（ACF1=-0.009，Q=5.4<11.07）→ episode 疑似随机切割，Gate A HOLD
  2. **B1：内生性极强**（指数+1%→当日流+245 亿，t=17.96，R²=0.784）
  3. **B2：E 对次日零信息**（每+100亿→次日 2.09bp，t=0.286；分组差 0.123%，t=0.53）→ **进攻侧跟随无证据**
  4. **B3：负影子**（指数+1%→次日 E -27.3 亿，t=-2.25，涨后兑现流出而非追涨）
  5. **对照组（最锋利）**：流入确认日 d1 后 5/10/20 日 **-0.8%/-1.5%/-2.2%**（比无条件差 -73/-151/-236bp）→ **确认流入再跟=系统性买在短期顶部**；流出确认日后 -0.25%/-1.28%/-1.94% → 回避有价值但与流入侧同为负，疑似共同源于**短期反转效应**（R_{t-1} 系数 -0.169，t=-2.33），防守特异性待宽度序列区分
  6. Gate 形式判：A HOLD（n=10 流入 episode、中位 4 日但白噪声）/ B 无信号 / C 形式 PASS（滞后占比 33%）但与对照组矛盾——**以对照组为准，进攻侧应 DOWNGRADE**
- **结论**：与"不对称现实·防守优先"预测一致——进攻侧零证据，防守侧初步证据但需特异性检验。**下一步 = P0.D 宽度序列重算器**（backtest_prices 三年重算 accum/distribution 标签→市场级宽度序列→样本 127 日→~730 日，唯一能把 n=10 变 n≈50+ 的路径）。
