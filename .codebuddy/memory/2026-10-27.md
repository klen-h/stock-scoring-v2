- **盘中会变的只有「① 盘中变化」**：前端 300s 轮询 `loadWorkbenchScan`；后端 `workbench_scan_loop`
  每 60s 巡检、只在 8 个采样点（09:45…14:45）真写一行。
- 其余三块都是**日频或按需**：`crowding_watch` / `key_level_watch` / `ai_basket_watch` /
  `scenario_watch` 全部读数据包与日批落库（`load(date)`），页面打开或切阶段拉一次，盘中不变；
  `observer_review` 是 LLM 按日缓存 + 手动触发。
- **「有料」不会推浏览器通知**：`workbench_scan_loop` 只写库 + print + status；
  通知来源是 `brief_loop`（快讯异动 → `/flash/notifications`）与教练体检卡。
- 「有料」= `score >= WORTH_SCORE(40)`，语义是"这半小时有实质变化"，**不含方向**；
  大涨与大跌都算有料，属口语化的流程词（值不值得说一句）。
- 若要改「正/反影响」：`_judge` 的 reasons 已带方向线索（idx_move 的 pct 符号、d_up_ratio、
  dlu/dld）；`sector_leader/rotate`、`volume`、`news*` 本身不分方向 ⇒ 建议
  **强度(score) 与方向(bias) 并存**：`bias = Σ dir*pts`，|bias|≥20 判正/反，否则"中性变化"。
