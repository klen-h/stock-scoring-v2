### 调度顺序（已确认安全）

```
15:10  zzshare 板块快照落库（plate_daily_zz）
19:30  daily_report_loop 生成日报        ← 晚于快照 ✓
20:43  daily_batch 再覆盖一次（同键）    ← 也晚于快照 ✓
```

⚠️ 日报标题里带 `截至 {date}`，**若快照当天落库失败会显示昨天日期** —— 这是故意的，
让人一眼看出数据没更新（而不是假装是今天的）。

### 性能代价

`ma_scan` 首次 5~8 秒（SQL 聚合下推），有 5 分钟缓存。
日报每天跑两次（19:30 + 20:43，跨进程缓存不共享）⇒ 多约 10~16 秒。
相对日批几分钟可接受。
