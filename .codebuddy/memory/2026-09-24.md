## 🧭 决策：缺口②（跨 tab 深链 / 选中态）**不做完整版**，只做「零成本通道路」

**用户问**：缺口②成本中等，建议做吗？

**核实后纠正了我自己上一轮的估计（上轮说「成本中等」= 低估）**：
1. `ScoreRank.vue:1152` `activeTab = ref('top')` = **纯进程内 ref、零 URL 联动** ⇒ 加深链要
   **新引入 `useRoute` + 双向同步**（现在只 import 了 `useRouter`，仅用于 push）；还会引入
   **新行为**（刷新后停留在某 tab），可能反而干扰。
2. **`switchTab` 带异步副作用链**：`switchTab('watch')` → `loadGateWatch().then(loadWatchPrices)`
   ⇒ 「定位到某行 + `scrollIntoView`」必须**等数据到位**才能做 ⇒ ★ **真正的复杂度在异步时序，
   不在 DOM**（加 `:id`/`:ref` + 高亮 class 本身只要几行）。
3. ★ **关键：「差什么」悬停就能看到** —— top 的 `3/3` 标签 `title` 里**已经**有 3 条判据的
   ✓/✗ + `hint` + 建议仓位 ⇒ 「切过去定位那只票」的边际收益只剩**省一次视觉搜索** ⚠️
4. **需求原文辨析**：缺口② 的定义是「缺 `?code=` 深链 + 选中高亮（**「在持仓/观察池中查看」
   小按钮**）」⇒ 括号里那个**小按钮才是真需求**；`?code=` 深链是我当初顺手写的**技术方案**，
   不是需求本身。
5. **URL 深链对单用户系统价值 ≈ 0**（不会把 `?tab=watch&code=002709` 发给别人，也不会存书签）。

**⇒ 结论：值「通道路」，不值「深链机制」。**
