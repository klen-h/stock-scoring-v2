### ★ 关键口径陷阱：`egress_stmt_raw` 是累计快照

表里 `day / queryid / calls / rows / ms / q`，**每天存的是 pg_stat_statements 的累计值**，
不是当天增量。证据：

```
11-04 ~ 11-12  每天 rows 都 ~2.6 亿（几乎不变）
11-13          骤降到 68 万（统计被重置）
11-16 ~ 11-20  从 738 万单调增到 1441 万
```

**必须按 queryid 做 LAG 差分**才是真实日增量（这正是迁移 skill 铁律 7 警告的坑）。

```

表上有 uq_backtest_prices_code_date(code,date) 唯一索引 ⇒ 窗口函数可行
```
