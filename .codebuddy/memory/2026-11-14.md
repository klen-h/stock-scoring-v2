## ★★★ 中国10Y国债"变动0.0"是假数据（`734dfd2e`）

用户："宏观依据明细的中国 10Y 国债变动(bp) = 0 · 当前 0.0，多需 < -2 / 空需 > 3
⇒ 未达阈值是正常的吗" —— **不正常，是真 bug。**

### 现象

`macro_daily` 里 **11-04 ~ 11-13 连续 8 个交易日** `cn10y.price == prev_close`
⇒ `cn10y_bp_change` 恒为 **0.00**。11-03 之前正常（-0.10 / -1.10 / +2.60 / -1.20）。

### 根因：东财"全字段同值"残缺包

那几天新浪 `globalbd_cn10yt` 拉不到（快照自带 **`source="eastmoney"`**），
走东财兜底时返回的是 `f2(现价) = f15(高) = f16(低) = f18(昨收)`、`f3(涨跌幅) ≈ ±0.01`
的**自洽但无信息**的包（东财在数据未刷时就这样给）。

**⚠️ 关键认知：不是 `f18` 缺失，是 `f18` 被抄成了 `f2`。**
⇒ 任何"判断字段是否存在"的守卫**都抓不到**，必须判**是否相等**。

### 为什么 8 天没人发现（最值得记的一条）

`cn10y_liquidity` 的区间是 `-2 < bp < 3`，**假 0 正好落在"未达阈值"**
⇒ 界面显示"当前 0.0，多需 < -2 / 空需 > 3 ⇒ 未达阈值"，**看起来完全正常**。

两个真实代价：
1. **真信号被永久漏掉**（真涨 >3bp 也显示 0.0，永不触发）；
2. **稀释 china 组分母** —— `组得分 = Σ(方向×强度) / Σ强度`，
   假 0 让这条规则"有数据但中性"，把同组其他规则的权重**摊薄**
   （组内 2 条时 1.0/2.0=0.5，1 条时 1.0/1.0=1.0）。

**⇒ 教训：一个"永远不触发"的规则，比报错的规则危险得多 —— 它不吵不闹，只是静默地不存在。**

### 修复 `_yield_bp`

```python
if p == pc:            # 残缺包：昨收被抄成现价
    return None        # 不给 0
```

规则引擎对 `None` 的处理本来就是对的：`"无数据（该条不计分，也不计入分母）"`。

**三个设计取舍（都有理由）**：
- **只在消费端拦截，不改 `_fetch_em` 的 `prev_close` 本身** ——
  置 `None` 会让别处裸运算抛 `TypeError`（金银比 `s_["prev_close"] > 0`、
  利差 `us10["prev_close"] - us2["prev_close"]`）。影响面最小。
- **判"完全相等"而非"|chg| 极小"** —— 相等是残缺包的**确定特征**；
  极小但不等可能是真实微幅变动，会误杀。
- `us10y` / `us2y` 同源兜底，一并保护；`us_curve_bp_change` 改用 `Δ10Y − Δ2Y`。

## ★★★ 宏观分数择时的三个候选方案：只有「重校准 3pp」值得做

用户给了三个下一步选项，问建议。**结论：做①，不做②，③的结论已经明确（不必再测）。**

### 前置事实：样本扩不了（硬约束）

- `macro_daily_history` 只有 `code/date/close`（**行情**，不含宏观分数）
- `macro_daily` 只有 **51 天**（08-24 起），`rules_detail` 只有 **12 天**（10-29 起）
- ⇒ **历史宏观分数只有 51 天，无法扩到 5 年**

**⇒ 打钩期只有 14~15 个决策日。在这个样本上做任何阈值优化都是过拟合。**

### 先排除一个错误猜测

我曾怀疑分数被「长期恒亮的水平规则」压出结构性偏空（`us10y_high`/`us30y_high`
注释自承"在当前制度下会长期点亮"）。**实测：两条确实 12/12=100% 触发，

⇒ 结构性偏空存在但**幅度小**，不是主因。

### 关键数据：把策略拆成「进攻」与「防守」

全量 44 个有效决策日（`macro_daily` 51 天 ∩ 价格覆盖），T+1：

| 分组 | n | 权重(上证50) | 成长(创业板) | 差(成长−权重) |
|---|---|---|---|---|
| 全部（基准） | 44 | -0.058% | -0.782% | **-0.724pp** |

| ③ \|score\|>20 才动 | 11 | -0.061% | -0.981% | -0.920pp |

策略模拟（全量 44 天，不含成本）：

| 策略 | 累计 | 切换次数 |
|---|---|---|
| A 原策略（>0 成长 / <0 权重） | **-17.20%** | 16 |
| B \|score\|>20 才切 | **-7.06%** | 3 |
| C 只做防守（= 一直持上证50） | **-2.59%** | 0 |

**三条结论：**

1. **`score>0` 买成长是错的，30 个样本稳定为负**（成长 -0.643% vs 权重 -0.137%）。
   这是原策略亏钱的主因。
2. **`score<0` 持权重是唯一站得住的**（权重 **+0.112%**，是表里唯一的正收益）。

则 C 等价于**一直持上证50**（基准，不是策略）；若理解为"空仓"，

## ★★★ 落地①：风格分化换成上证50，阈值 3.0 → 4.0（`b1790bf9`）

### 反直觉的实测：上证50 的分化度波动**更大**，不是更小

我原以为"上证50 波动小 ⇒ 分化度小 ⇒ 阈值要降"。**反了。**

3 年日线（721 / 733 个共同交易日）实测"近 5 日 权重 − 创业板"：

| 指标 | 沪深300 | 上证50 |
|---|---|---|
| 标准差 | **2.97** | **3.79（大 27%）** |
| P10 / P90 | -3.20 / +2.99 | -4.12 / +4.07 |

**为什么**：纯权重（银行/保险/白酒）与创业板的相关性**更低**，
差值反而更宽；沪深300 混了中盘成长股，与创业板部分重叠，把差值"对冲"掉了。

**⇒ 教训：不要用"单一变量波动小"去推断"差值波动小"，必须实测。**

### 阈值校准：3.0 → 4.0（触发率完全对齐）

| 阈值 | 沪深300 触发率 | 上证50 触发率 |
|---|---|---|
| 2.0 | 35.9% | 49.7% |
| 3.0 | **21.8%（原口径）** | 31.8% |
| 4.0 | 12.0% | **21.8%（完全吻合）** |

单边也吻合：权重主导 10.4% vs 10.0%，成长主导 11.4% vs 11.9%。
**⇒ 校准原则 = "让'明显分化'的日子占比不变"，而不是拍一个数。**

### 效果验证 + 我必须如实说的局限

17 个 gate_add 触发日中有 14 个同时具备"前 5 日历史 + 后 5 日价格"：
沪深300@3.0 与上证50@4.0 的 **9/5 分组完全相同**
（强分化 创业板 T+5 **-3.38%** vs 弱分化 **-6.13%**，差 2.74pp）。

**⇒ 切换不改变现有结论（稳健），但不能宣称"新口径更好"** —— 样本太巧、太小。
**真实价值是语义正确（纯权重 ≠ 混中盘的沪深300），不是效果提升。**

### 同源化（这才是防复发关键）

`rules.py` 里曾有 **3 处硬编码 `3.0`**（473 / 536 / 797）+ `_direction_hint` 默认参数。
换标的后若只改 `style_spread`，这 3 处会**静默用旧值** —— 正是项目踩过的
"两处各写一份、换标的只改一处"（`_bench_code` 那次）。

**修法**：
```python
from app.style_spread import SPREAD_THRESHOLD as _STYLE_THR
from app.style_spread import WEIGHT_LABEL as _STYLE_WEIGHT_LABEL
def _direction_hint(..., thr: float = _STYLE_THR):   # def 时求值，容易漏
```
⚠️ `_direction_hint` 的 `thr` 是**默认参数（def 时求值）**，
所以 import 必须放在 `def` **之前**（已在 578 行、`def` 在 582 行，顺序 OK）。

**前端同理**：`Workbench.vue` 有 3 处写死"沪深300"（tooltip / 标签 / bar title）。
