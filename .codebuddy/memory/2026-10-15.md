## 68 新工具：形态胜率验证 `scripts/pattern_launch_check.py`（用户指派「设计量化分析工具」）
- **形态**：缩量调整（pullback_days 窗口 + 均量≤vol_shrink×基准 + 调整幅度区间 + 不创新高）
  → 启动日（涨幅≥launch_pct + 放量≥vol_surge× + 突破调整高点）；冷却去重。
- **评估**：入场 T+1 开盘；前视 T+N（默认 10，可多窗口）；胜率/均收益/中位/区间最大涨幅/
  最大回撤/达标率；基准=self（同股无条件）或 market（全市场无条件）；按信号日聚类 bootstrap
  P(均值≤基准)；样本闸 <20 ⇒ INSUFFICIENT。
- **数据源**：`--source auto|db|zzshare`，单股默认 db（新鲜、含最近启动），全市场默认 zzshare
  （大样本）；单源绝不混源。输出 MD + 自包含 HTML（内联 SVG：事件研究/收益分布/分年度/价格标注），
  落 `backend/backtest_reports/`（该目录 git 跟踪，已 29 份）。`--selftest` 3 组用例过。
- **实测结果（500 只 / 2024 起，默认参数）**：256 样本 / 180 独立日，胜率 41.0%、均 −0.38%、
  中位 −1.92%；基准均 −1.28% ⇒ 超额 +0.91pp，P(≤基准)=0.105 —— **不显著、胜率<50%**，
  即「缩量调整→放量启动」在此样本上**不构成上涨预测**（只是跌得比市场少）。
  600777 单股：默认参数近 3 年 **0 信号**（启动是 10-09/10-12 温和放量爬坡，非单日 +5%）；
  放宽到 launch≥2.5% 仅 1 信号（2024-12-09，T+5 −4.35%）。⇒ 单股样本天然不足，靠全市场。
- **踩坑（已修）**：① `all_codes_zz` 返回带后缀码，`_suffix` 再套一层 → 全市场 0 数据，修成幂等；
  ② 图表函数空样本崩溃（mx=0、路径解包），加空值护栏；③ 独立信号日须 set 去重。
