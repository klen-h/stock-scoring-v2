### 三、★ 用户"前三天 k线 actions 都 OOM 重启"——**不成立**（已核对）

- 被记录到的重启**都在 Render 后端**（告警正文自带实例 id `srv-…-hibernate-…`，那是 Render 服务实例）；
- GitHub Actions 跑在**独立 runner**（16GB），与 Render 500MB 进程内存**不共享**；
- `kline-data.yml` 的脚本是「逐只拉取 + 流式写 gzip」，峰值内存与包体积同量级（几十 MB）；
