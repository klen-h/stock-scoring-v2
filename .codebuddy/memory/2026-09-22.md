## 📐 regime 转档条件（用户问"转出 defensive 需要什么条件"，读 `market_regime.detect_market_regime`）
**判定状态机**（按优先级，`backend/app/backtest/market_regime.py`）：
1. 高波动(ATR分位≥80) + MA 向下 → **DEFENSIVE**（恐慌）
2. MA 向上 + ADX≥20 + 波动非高 → **OFFENSIVE**
3. MA 向下 + ADX≥20（moderate/strong） → **DEFENSIVE**（现状）
4. ADX<20（无趋势） → **NEUTRAL**
5. MA 向上但价格<MA20-2% → NEUTRAL（回调观望）
6. MA 向下但价格>MA20+2% → NEUTRAL（**反弹观望，最可能先走这条**）
7. 低波动(ATR分位≤20) + 价格贴均线(±1.5%) → NEUTRAL
+ **Hysteresis 3 天**（`HYSTERESIS_DAYS=3`：条件需连续满足 3 个交易日才切档）
常量：ADX_THRESHOLD=20、ADX_STRONG=35、VOL 高/低=80/20（分位）。
**当前实测（9-18 收盘）**：ma20=4548.7、ma60=4654.8（比 0.9772→down）、ADX=24.9（moderate）、
波动分位 50（normal）、价格距 MA20 **-0.91%**（贴得很近）⇒ 落在 case 3。
**转出路径与距离**：
- ① 反弹（最快）：价格需 MA20×1.02 ≈ **4640（约 +1.9%）** 且持续 3 天 ⇒ NEUTRAL
- ② 趋势衰减：ADX 从 24.9 降到 **20 以下** ⇒ NEUTRAL
- ③ 趋势反转：MA20 需升到 ma60×1.005 ≈ **4678（约 +2.8%）**+ADX≥20 ⇒ 直接 OFFENSIVE
⇒ 指数若站稳 **4640 附近 3 个交易日** 即转 NEUTRAL（可买档）；当前 4539（9-21）还差约 2%。

**★ 重要教训（PowerShell 陷阱）**：单行 `python -c` 里的裸 `>`（如 `extreme(>20%)`）
会被 PowerShell 当**重定向符** ⇒ 命令损坏、退出码 255 且**无任何输出**（今日多次误判为
"Supabase 抖动"）。以后命令里禁用裸 `>`，输出文案用"超20"等替代。
