### 二、Egress 归因（pg_stat_statements 实测；累计 98.5M 行 / 37 天 ≈ **430MB/天**，与页面 429MB/天吻合）
| # | 语句 | 调用 | 返回行 | 估算 |
|---|---|---|---|---|
| 1 | `SELECT ... FROM mainflow_history ORDER BY code,date`（整表） | 191 | **20.0M** | ≈1.7GB |
| 2 | `backtest_prices ... WHERE code = ANY(ARRAY[...])`（回测批读） | 748 | **18.9M** | ≈1.4GB |
| 3 | `backtest_prices WHERE code=$1 ORDER BY date ASC`（逐只全历史） | **9,463** | 6.96M | ≈500MB |
| 4 | `backtest_prices ... code IN (...)`（研究脚本批读） | 12+49+93+… | ≈13.7M | ≈1GB |
| 5 | `stock_finance_ocf_hist ORDER BY code` | 115 | 2.39M | ≈120MB |
| 6 | **DDL 反复执行**（CREATE TABLE/ALTER/INDEX 各 400~935 次）| ≈5,700 | — | 每次触发 PostgREST schema 全量重载（隐形） |
- **结论**：日常 430MB/天的大头是 **backtest_prices 全量读（≈3GB 累计）+ mainflow_history 整表读（≈1.7GB）**，
  来源是**研究脚本与被用户触发的回测**，不是日批精算（`live_ranking` 走 kline_cache/indicator_cache，不读 backtest_prices ✓）。
