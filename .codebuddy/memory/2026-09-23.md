3. **唯一带 LLM 解读的规则**（用户三想法的落地）：prompt = 触发事实 +

## 🔬 冲高回落形态预测力检验 ⇒ **NO EDGE**（`6d38674`）
**动机**：上一步只验了阈值频率（会不会天天响），**没验**「响了有没有预测力」。
**工具**：新增 `scripts/reversal_edge_check.py`（判定标准**预先定死**，防事后挑格子 ——
沿用项目研究脚本纪律）；`backtest_prices` sh000300 全历史 **748 根日线**
（2023-08-23..2026-09-22）；该表**无 sh000001** ⇒ 用沪深300 代量级。入场点 = 触发日收盘。

| 组 | n | T+1 均值 | T+1 胜率 | T+5 均值 |
|---|---|---|---|---|
| A 冲高回落（触发） | 110 | +0.19% | 51.8% | +0.57% |
| B 冲高守住（**最相关对照**：同为冲高日） | 127 | +0.09% | 52.4% | +0.35% |
| D 没冲高 | 510 | −0.01% | 50.2% | +0.02% |
| C 全样本 | 747 | +0.03% | 50.8% | +0.16% |

⇒ A−B：T+1 **+0.10pct**、T+5 +0.22pct ⇒ 主判定 **NO EDGE**。
**结论（与直觉相反）**：『冲高回落 = 派发看跌』**不成立** —— 该形态本身不携带看跌信息。

**⇒ 最重要的产出是改了 LLM prompt 语义**（`_reversal_llm_note`）：prompt 里**显式写入**
该检验结论 + 禁止 LLM 据此给减仓/看跌建议，定位改为「**盘面结构提示**」。真调 LLM 对比：
- 旧 prompt：「弱势反弹失败…不加仓、不追高、跌破日内低点则减仓」← 方向性建议，数据不支持
- 新 prompt：「攻势逐步被消化、未改变防御基调」+「**该形态不构成对持仓的操作依据**」+「无需动作」
⇒ 防住「把无预测力的形态当交易信号用」（同白名单负期望那类错误）。

**副发现**（仅记录；n=16 噪声大，不设规则）：A 组内**触发日收绿**的样本 T+1 **+0.88% /
胜率 81.2%**，但 T+5 转负（−0.13% / 37.5%）⇒ 疑似短线超跌反弹、一天即衰竭。
**局限**（已写入脚本）：①日线 low 是**触发上限**口径（3 分钟轮询实际更少）②相邻触发日
样本重叠（独立样本 <110）③样本期仅 3 年、未跨市况 ④多重比较（4 个持有期）
⇒ 以**预登记的 T+1 主判定**为准。
