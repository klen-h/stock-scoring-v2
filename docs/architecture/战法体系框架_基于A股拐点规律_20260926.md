# 战法体系框架重设计：以 A 股拐点规律为地基

> 生成日期：2026-09-26
> 定位：**框架逻辑设计**，不是 PLAN、不是对既有代码的裁决书。文中所有结论都需经回测 → 模拟盘 → 生产三级验证后方可落地。
> 写作立场：**从 A 股历史拐点（转熊 / 阴跌 / 反弹 / 反转）的真实规律出发，独立推导**，不沿用任何既有文档的"周期/季节"框架。

---

## 一、为什么要回到"拐点"来重新审视

现有战法体系的核心矛盾，可以用一句话概括：**用同一套选股动作去应对性质完全不同的市场阶段，然后指望一个全局白名单来兜底**。

这个矛盾的根源不在战法本身，而在**准入的维度错了**。当前准入的单位是"战法"——一个战法好不好，靠它在**全历史、全状态**下的平均期望来判定。但 A 股的历史反复证明：**同一个战法在牛市和熊市的期望值方向是相反的**。

- 一个"回调低吸"战法，在上升趋势中是吃回调的正期望工具；
- 同一个战法，在阴跌市中是"接飞刀"的负期望工具。

如果准入只按"战法"平均成绩来定，结果必然是两种：要么因熊市拖累把好战法误杀，要么因牛市战绩把坏战法放行——**二者都是错的**。

所以框架重设计的起点只有一个：**先回答"现在市场处于拐点之后的哪个阶段"，再决定"允许用哪些动作"**。拐点，才是战法体系真正的第一性单位。

## 二、A 股拐点的本质规律

### 2.1 四个结构性事实（一切推演的前提）

**事实一：牛短熊长，且顶部多为尖顶、底部多为圆底。**
A 股历史上上涨周期短而剧烈，下跌与磨底周期漫长。顶部（2007 年 6124、2015 年 5178）往往是快速见顶、快速崩塌；底部（2005 年 998、2008 年 1664、2019 年 2440）则往往经历漫长的磨底与多轮探底。这决定了：**"跑得快"比"抄得准"在 A 股更值钱**。

**事实二：散户主导，情绪是同步甚至略领先的放大器，但并非可靠的反向指标。**
情绪（涨停家数、连板高度、涨跌比、成交活跃度）能刻画市场温度，但"冰点买入、亢奋卖出"这类机械反向操作在 A 股反复失效——**冰点之后可以更冰**。情绪的价值在"识别状态"，不在"预测拐点"。

**事实三：涨跌停 + T+1，放大了连板效应，也制造了"买不进"。**
最强的票在情绪高潮期往往一字板，看得见买不到；这导致"追最强"战法在回测里被系统性高估（回测能成交、实盘买不进）。

**事实四：政策是 A 股拐点的最重要外生变量。**
政策底、市场底、资金底（情绪底）三者常分离：政策底先出，市场底滞后，资金底最后确认。**三底分离**意味着任何单一信号都不足以确认反转。

### 2.2 四阶段的特征、案例与可操作性

我把 A 股一轮完整牛熊拆成四个可操作阶段。**注意：这不是线性循环，熊市内部可能反复在"阴跌—反弹"之间切换多次，反弹大多数失败、少数升级为反转。**

| 阶段 | 典型特征 | 历史案例 | 可操作性 |
|---|---|---|---|
| **转熊（顶部）** | 高位放量滞涨、龙头见顶、赚钱效应衰竭、政策收紧 | 2007-10、2015-06 | 右侧确认后**必须快跑**；顶部"尖顶"多，等完美卖点 = 挨跌 |
| **阴跌（主跌/磨底）** | 缩量、无量阴跌、反弹 1~2 天即夭折、热点涣散 | 2018 全年、2022 主跌段 | **几乎不可操作**；一切低吸均为负期望，唯一正确动作 = 空仓 + 观察 |
| **反弹（技术性反抽）** | 超跌急涨、量能脉冲、持续性差 | 2015 股灾后多次反抽失败 | **第一波不可追**；它与反转的唯一区别是"确认"，确认前都是赌博 |
| **反转（底部确认）** | 政策底→市场底→资金底相继兑现、放量突破关键均线、主线清晰、宽度扩张 | 2005、2008 底、2019 初 | 确认后进入**最佳窗口**：主线首次回调是黄金低吸点 |

### 2.3 哪些规律可用、哪些必须放弃（可交易性判断）

在动手设计框架前，先诚实地把规律分成三档，这是防止"把无预测力的形态当交易信号"的第一道闸门：

**可用（有可交易证据支撑的）：**
- **R1 反转确认后，主线板块的首次回调是正期望低吸点**——趋势确立后的回调，与阴跌市的下跌，性质完全不同。
- **R2 熊市 = 阴跌 + 短反弹**，反弹大多失败，需要右侧确认才能升级为反转。
- **R3 趋势向上时回调是机会，趋势向下时反弹是陷阱**——同一个动作，随状态翻转期望。
- **R4 反转需要多信号共振（政策 + 价格结构 + 资金/情绪），单一信号不足以确认。**

**不可用（历史反复证伪的）：**
- **预测顶部**——顶部是尖的，预测顶部 = 在最高点附近频繁误判。
- **抄 V 形底第一波**——V 形底的第一波上涨速度最快也最不可持续，且无法提前确认它是反转而非反抽。
- **机械的情绪反向**——"冰点抄底"在阴跌市是负期望。
- **打板 / 追一字板**——回测能成交、实盘买不进，期望被系统性高估。

**明确不知道（需要数据积累后才谈）：**
- 情绪从"领先"到"反向"的精确切换阈值——这需要足够长的、带标签的历史数据才能拟合，不能拍脑袋。

## 三、核心设计原则（五条，全部由第二节推导）

1. **状态先于战法（先定势，再选招）。** 战法与市场状态必须**强制绑定**，不是"推荐关系"。同一战法跨状态使用 = 用错工具。

2. **防守是默认态。** 牛短熊长意味着 A 股多数时间不可进攻。**空仓 / 轻仓才是正确默认态，进攻需要"许可证"**（反转确认）。

3. **右侧确认，不预测拐点。** 所有状态切换都只承认"已经发生的转折"，不预测"将要发生的转折"。宁可慢一步，不可抢半步。

4. **分层分级，每层独立验证。** 状态层（定势）、战法层（选招）、执行层（定点）三层各自回测，不混为一谈；横截面证据（选股）与时间序列证据（择时）严格区分。

5. **诚实放弃。** 明确划出"不赚的钱"（V 底第一波、打板、阴跌抄底、全天候圣杯），这比"什么都要抓"更能保护本金。

## 四、框架总览：三层一矩阵

```
┌─────────────────────────────────────────────────────┐
│  第一层 状态机：市场处于哪个阶段（拐点之后的位置）      │
│    S0 空仓态 → S1 观察态 → S2 进攻态 → S3 撤退态       │
├─────────────────────────────────────────────────────┤
│  第二层 拐点协议：状态之间的切换条件（全部右侧确认）     │
│    转熊协议 / 阴跌协议 / 反弹识别 / 反转确认             │
├─────────────────────────────────────────────────────┤
│  第三层 战法矩阵：战法 × 状态 的准入格子（强制）        │
│    A 低吸族 / B 趋势族 / C 防守族                       │
├─────────────────────────────────────────────────────┤
│  执行层：仓位上限 + 止损铁律 + 持有期纪律（贯穿始终）    │
└─────────────────────────────────────────────────────┘
```

关键洞察：**拐点的意义不是"预测"，而是"触发状态切换"**。状态机是"果"，拐点协议是"因"；战法矩阵是"在不同状态里该用什么"的许可证表。

---

## 五、第一层：状态机（四个状态，按可操作性递增）

状态设计不追求学术完备，只追求**每个状态对应一个明确的仓位上限和明确的动作集**。

| 状态 | 含义（对应拐点阶段） | 仓位上限 | 允许的动作 |
|---|---|---|---|
| **S0 空仓态** | 阴跌主跌段（转熊后、反转前） | **0** | 空仓；仅 C 族（主线监测、备弹药） |
| **S1 观察态** | 底部区 / 反弹疑似（反转未确认） | **轻仓（如 ≤20%）** | C 族 + A 族**限仓试错**；不追、不重仓 |
| **S2 进攻态** | 反转已确认 / 上升趋势中 | **重仓（如 ≤80%）** | A 族 + B 族全开；主线首次回调为黄金点 |
| **S3 撤退态** | 顶部区 / 转熊已确认 | **降至 0** | 减仓→空仓；C 族（防止再进场） |

要点：
- **默认态是 S0 / S1**：A 股多数时间待在这两个防守状态。
- **S2 是"许可证状态"**：只有反转确认后才进入，且进入后仓位才允许放大。
- 状态之间**不允许跳变**（S0 不能直接跳 S2），必须沿 S0 → S1 → S2 → S3 → S0 的路径走，且每一步切换都要过拐点协议。

---

## 六、第二层：拐点协议（四条，全部右侧确认）

这是框架的核心。四条协议分别对应 A 股四个拐点，**每一条都只承认"已经发生的转折"**。

### 6.1 转熊协议（S2 → S3，进攻转撤退）

触发（**多条件共振，不是单点**）：
- 主线龙头放量见顶（连板高度断板、领涨股跌破关键均线）；
- 指数跌破关键均线（如 MA20 / MA60）；
- 赚钱效应衰竭（涨停家数、晋级率、涨跌比连续走弱）。

动作：**不抄底、不等反弹，右侧确认即减仓到 0**。顶部是尖的，"跑得快"优先于"跑得准"。宁可卖早被小抽，不可卖晚挨重挫。

### 6.2 阴跌协议（S3 → S0，撤退转空仓）

触发：指数持续在均线下方 + 缩量阴跌 + 反弹 1~2 天即夭折（反弹无力）。

动作：**空仓 + 主线监测**。此时"A 低吸族"全部禁入（这是负期望阶段）；唯一保留的动作是"监测哪些板块在抗跌 / 逆势走强"，为未来反转后的主线预埋伏笔——**只备弹药，不开枪**。

### 6.3 反弹识别协议（S0 → S1，空仓转观察）——**分两层，最关键**

反弹与反转的区分是 A 股最难的问题，因此这一步**必须分两层**：

- **第一层（情绪先行 → 只观察）**：情绪冰点后回暖（涨停家数回升、涨跌比改善、恐慌情绪释放）⇒ 进入 S1 观察态，**但只观察，不进仓**。因为情绪回暖可能是"死猫跳"。
- **第二层（结构确认 → 才解禁）**：宽度扩张（上涨家数占比持续抬升）+ 指数放量站上关键均线 + 出现清晰主线 ⇒ 才允许进入 S2 进攻态。

**核心纪律：情绪先行信号只能升级到"观察"，不能直接升级到"进攻"。** 这一条直接堵死"把反弹当反转、把死猫跳当底部"的最大亏损来源。

### 6.4 反转确认协议（S1 → S2，观察转进攻）

触发（**三底相继兑现**）：
- 政策底已出现（政策转向 / 流动性宽松）；
- 市场底已确认（指数不再创新低、二次探底不破前低、放量突破）；
- 资金底 / 情绪底在跟进（成交量放大、主线板块资金持续净流入）。

动作：进入 S2 进攻态，**B 族趋势战法的"主线首次回调"窗口只开一次**——这是本轮周期里赔率最好的买点，错过不追。

---

## 七、第三层：战法矩阵（战法 × 状态，强制准入）

准入单位从"战法"改为"**战法 × 状态**的格子"。同一个战法在不同格子里是**不同的东西**，独立回测、独立期望。

```
          S0空仓   S1观察    S2进攻   S3撤退
A 低吸族    ✗       ⚠️限仓    ✓        ✗
B 趋势族    ✗       ✗        ✓        ✗
C 防守族    ✓       ✓        ⚠️       ✓
```

### 7.1 A 族（低吸族，回调买入型）

- 本质：吃"上升趋势中的回调"（R1 / R3）。
- **只在 S2 生效**；S1 仅限仓试错（收集样本、验证信号质量）；S0 / S3 一律禁止。
- 这是现有战法的主体，**不推翻、只加状态门控**：它们的负期望主要来自"在阴跌市被错误使用"。

### 7.2 B 族（趋势族，反转后的主升段）

- 本质：吃"反转确认后的趋势延续"，即 R1 的"主线首次回调"与主升段突破。
- **只在 S2 生效**，且以"主线首次回调"为首要形态。
- 这是现有体系**缺失的一族**——没有它，框架在 S2 里就只有"低吸"没有"顺势"，等于放掉了反转后最肥的一段。

### 7.3 C 族（防守族，空仓 + 监测）

- 本质：S0 / S1 / S3 的默认动作 = 空仓 + 主线监测 + 备弹药。
- 它**不是"什么都不做"**，而是"主动观察哪些板块在抗跌、哪些资金在逆势布局"，为反转后的 B 族主线选择做前置准备。

### 7.4 矩阵的验收门槛

每个格子（战法 × 状态）**独立**回测，独立满足正期望（如期望收益 > 0 且盈亏比 ≥ 阈值）才准上线。**禁止用一个"跨状态平均期望"来代表一个战法**——那正是现有体系把负期望战法放行、把好战法误杀的根源。

## 八、执行层：贯穿始终的风控与纪律

执行层不因状态改变而打折，是框架的"底线"：

1. **仓位上限由状态决定**（见状态机表），任何单笔、单战法不得突破当前状态上限。
2. **止损是铁律**：无论 S2 的进攻还是 S1 的试错，止损都必须前置、无条件执行。
3. **卖出依据是持仓视角，不是买入闸门**：买入资格的降级 ≠ 持仓必须卖出。卖出走止损 / 破位 / 持有期纪律，不能拿"买入信号消失"来驱动卖出（这是两类完全不同的决策）。
4. **执行一致性**：已决策的动作要落地，用"执行率"而非"猜对率"来评价体系。

---

## 九、诚实放弃清单（"不赚的钱"）

1. **V 形底第一波**：无法提前确认是反转还是反抽，放弃。
2. **打板 / 追一字板**：回测可成交、实盘买不进，期望虚高，放弃。
3. **阴跌市的全部低吸机会**：负期望，放弃（唯一动作是空仓观察）。
4. **预测顶部/底部的"神算子"目标**：只做右侧确认，不追求抄在最低、逃在最高。
5. **全天候圣杯**：不存在能穿越所有状态的单一战法，放弃寻找。

这五条的共同作用是：**把能量从"什么都想抓"收敛到"只在 S2 进攻态里赚确定性的钱"**。

---

## 十、实施路径与验收门槛

实施顺序按"依赖驱动 + 风险最小"排列，每一步都有可验收的产出：

| 序号 | 步骤 | 产出 / 验收 |
|---|---|---|
| ① | **分状态回测**：把现有战法按 S0~S3 四态分别回测，验证"同一战法跨状态期望翻转"的假设是否成立 | 每个战法得到四态期望矩阵；这是**一切后续的前提**，零生产风险 |
| ② | **B 族趋势战法定义与回测**：定义"主线首次回调"形态，回测其正期望 | B 族在 S2 态的正期望证据 |
| ③ | **状态机 + 拐点协议落地**：把四条协议转成可计算的规则（均线、宽度、情绪阈值） | 状态切换规则，先离线跑历史验证，不接生产 |
| ④ | **战法矩阵上线**：扫描层加"状态门控"，准入按格子 | 战法信号只在对应状态产出 |
| ⑤ | **执行层接入**：仓位上限、止损、卖出纪律按状态绑定 | 与教练/风控模块联动 |
| ⑥ | **全链路验收**：回测 → 模拟盘 → 生产三级 | 每级通过才推进下一级 |

**验收铁律**：任何新规则、新阈值，必须**先回测出可交易的正期望**，再谈上线；"无回测不上线"是本框架与项目既有纪律的共同底线。

## 十一、框架与拐点规律的一一对应（收束）

| A 股拐点 | 框架落点 | 核心动作 |
|---|---|---|
| 转熊（顶部） | 转熊协议 → S3 撤退态 | 右侧确认，快跑空仓 |
| 阴跌（主跌） | 阴跌协议 → S0 空仓态 | 空仓 + 主线监测备弹药 |
| 反弹（反抽） | 反弹识别协议第一层 → S1 观察态 | 情绪先行，只观察不进仓 |
| 反转（底部确认） | 反弹识别第二层 + 反转确认 → S2 进攻态 | 结构确认后，B 族主线首次回调重仓 |

**一句话总结这个框架**：

> 承认 A 股"牛短熊长 + 顶部尖、底部圆"的现实，把默认状态设为防守；只在反转被右侧确认后，才把仓位和战法放出来；战法的准入单位从"战法"细化为"战法 × 状态"，让每个动作只在自己有正期望的那个阶段被使用。
