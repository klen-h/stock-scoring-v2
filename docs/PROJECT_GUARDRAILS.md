# 项目硬约束（Guardrails）· 一页版

> 用途：交给任何执行方（人或 LLM/agent）**在动手前必读**。
> 每条都是项目里**已经踩过坑**才写下的，不是风格偏好。
> 违反任一条 → 变更不予合并，已上线的按回滚流程处理。

## 0. 变更边界

- 只允许在分支 `chore/cleanup-YYYYMMDD` 上做清理/文档类改动；`main` 由 PR 合入。
- **删除任何文件前必须先输出清单待确认**（`git mv` 归档不算删除，但要保历史）。
- 不修改生产环境变量（Render / GitHub Secrets）；需要时只写「建议变更」到文档。

## 1. 数据包发布纪律（2026-10-24 事故）

- **前端改动禁止使用 `scripts/publish_packs_local.py`**。
  它是 **orphan 重建**（force push 整条 `gh-pages` 只含本地文件）⇒ 本地包旧就会把线上新包整批删掉
  （实测把工作流刚发布的 10-23 K 线包回滚成 10-22）。
- 正确姿势：**直接 push**，由 Actions 部署（`keep_files: true` 不会动 `data/`）。
- 只有本地确实生成了**更新**的包时才用该脚本；护栏已加：本地日期 < 线上 → 拒绝发布
  （`--force` 绕不过，需 `--allow-downgrade`）。

## 2. 时点诚实（最容易犯）

- 不得用「请求时刻」顶替「数据时刻」；每张卡必须能说明数据截至哪天/哪一刻。
- 数据缺失 ⇒ 显示「数据不足 / —」，**不得填 0**（0 与缺失必须可区分）。
- 当日数据未就绪 ⇒ 明确写「待日批（指数截至 X）」，不得用单一宏观读数翻情景。

## 3. 接口与性能

- **接口内禁止做全市场同步拉取**（`refresh_all_stocks` 实测 14s，会阻塞事件循环）。
  只能读缓存；缓存空就如实降级，预热交给调度器。
- 单接口 fail-open：辅助数据失败只丢该块，绝不拖垮整张卡/整个接口。
- 新增 60s 级轮询接口，必须能承受「页面开一天」：优先读库/缓存，必要时加进程内 TTL 缓存。

## 4. LLM 使用纪律

- **默认不自动触发**；展开/点按钮才调用；结果**按日缓存 + 数据指纹（sig）**，
  读数变了才算过期（`trader_brief` 早产缓存、`flash_brief` 指纹都是先例）。
- 一次刷新**最多 1 次** LLM；多条内容要**批量打包**进同一个 prompt，不得逐条调用。
- 线上业务受 `LLM_DAILY_MAX_CALLS` 日熔断保护；**批量实验必须独立记账**，
  不得写 `llm_usage_daily`，否则盘中简报/复盘会被打熔断。
- 输出必须结构化（JSON + 代码侧校验 + 失败降级模板），禁止让前端「解析自然语言」。

## 5. 观察器 / 解读类不进决策链

- 观察器、AI 解读、情绪卡等**不改评分、不进买入闸门、不碰模拟盘**。
- 不给「买入/卖出/加减仓/止损止盈」指令式建议；观察位只描述价格行为。
- 历史快讯/新闻只能作**证据**，不能替代盘口与资金数据；无命中不得声称有依据。

## 6. 同一份数据只渲染一处

- 项目多次因「同源两处渲染」出问题（教练卡、系统时间线、情绪预判数字）。
- 新增卡前先确认：这份数据是否已有展示位；有则在原处增强，不复制。

## 7. 前后端契约

- 涨跌停/连板等口径**只允许一个实现**：`app/limit_stats`（rt_k 精确优先 → 板幅 ST5/10/20/30cm）。
  禁止再写 `>=9.5 / >=9.9` 一刀切。
- 字段新增要**加列不加义**：老前端不升级不能崩（`extra_json`、`cached`、`as_of` 兼容模式）。

## 8. 前端

- 深色主题令牌：`bg-bg / bg-card / border-border / text-muted / text-rise / text-fall`；
  新增底色至少与 `#161b22` 有可见色差（`bg-white/[0.02]` 肉眼不可辨，别再用）。
- 工作台内跳转一律**新开标签**（`target="_blank" rel="noopener"`）——工作台是重页面，
  同标签往返会整页重挂载、重拉数据。
- 模板引用未声明变量**不会让 build 失败**（只在运行时炸）⇒ 新增绑定必须 grep 一次脚本侧声明。

## 9. 注释与留痕

- 注释写**为什么**，不写「做了什么」；关键决策留**日期 + 用户原话 + 事故经过**。
- 修复类改动必须写「根因 + 复现条件 + 为什么这样修」，否则下次会改回去。
- 日志一律 ASCII（生产控制台 GBK/编码问题），中文提示走返回值不走进日志。

## 10. 提交与验证

- 每个改动必须给出**验证方式**（跑了什么命令/看了什么输出），不能只说"已修改"。
- 前端改动：`npm run build` 通过 + 关键交互点一次（展开/折叠/空数据态）。
- 后端改动：`python -m py_compile <file>` + 至少一次真实调用（缓存命中路径与被拦截路径各一次）。
- 清理类改动：`git mv` 保历史；改完后全仓 grep 一遍旧路径引用。

## 11. 吞异常必须可见（2026-10-24 追加）

- **禁止 `except...: pass`**（同except 块内至少要有：计数、ASCII 日志、或显式 reason 字段三选一）。
  依据：2026-10-24 全量审查发现**同一形态静默死亡 ×4** —— `scheduler.py` A4 交易计划触发门
  （NameError 被吞 ⇒ is_open 恒 False，整条止损/兑现/买点提醒链不跑）、反静默巡检兜底分支、
  flash_brief 缓存 TTL 判断、database DDL 假成功。`scripts/code_hygiene_check.py` 的
  `except_pass` 棘轮基线拦新增。
- **失败必须可观测**：日批任务失败必须进 fail_list（exit 1 + 告警）；循环内关键判断被吞时
  至少 print 一行 ASCII，让"功能为什么没跑"能被 grep 到。

## 12. 鉴权默认化（2026-10-24 追加）

- **新增路由默认挂鉴权依赖**（`routers/auth.py` 的 verify_token 机制）；匿名可用的只读端点
  必须显式加入白名单并在 docstring 写明理由。
- **写操作/重计算/外呼端点一律不允许匿名**：烧 LLM、推企微、触发抓取（东财/新浪/巨潮）、
  回测重算、模拟盘 close/cancel 等——匿名触发即资源滥用/封 IP 攻击面
  （审查实证：`routers/flash.py`、`routers/paper.py`、`routers/sector.py`、
  `routers/backtest.py`、`routers/stock.py /finance-refresh` 等 5 组曾全裸奔，见
  `docs/BACKLOG.md` BK-04a~d / BK-39 / BK-40）。
- JWT_SECRET 未配置时**不得回退可预测值**（机器名）——宁可启动失败（fail-closed），
  也不伪造一个能被猜出密钥的鉴权体系（审查实证 BK-04b）。
