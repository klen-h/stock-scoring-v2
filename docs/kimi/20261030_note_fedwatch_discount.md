# 备忘：FedWatch / 加息概率引用折扣（简报第 3 项）

> 来源：`docs/kimi/20261030_fed_chair_speech_brief.md` 第五节第 3 条
> 状态：**转备忘，不改代码**（2026-10-30）

## 一、现状核查

全项目搜索（`backend/` `frontend/` `scripts/`）：

```
FedWatch | fedwatch | 加息概率 | 降息概率     →  0 命中
```

**结论：当前没有任何模块展示"市场定价的加息概率"。** 因此这条**没有可改的对象**，
不是"改不动"，而是"还不存在"。

## 二、为什么仍然要建这条备忘

主席讲话明确否定了这类前瞻信息的可靠性：

- "不要相信前瞻性指引，除非发生危机"
- "不要预设会议结果"
- "不会分享对 12 月将发生之事的看法"

而这套系统的历史教训是：**一个看起来精确的概率数字，比"不知道"更容易被误用**——
2026-09-17 排障时就被"402 掩盖成 429"误导过，同类风险。

## 三、约束（未来引入时必须遵守）

凡展示"市场定价加息概率 X%"的模块：

1. **必须标注数据来源**：FedWatch 隐含概率 / 调查 / 模型推算，三者含义完全不同。
2. **必须标注数据时点**：不能写"当前"，要写"截至 MM-DD HH:MM"。
3. **必须打折或标不确定性**：建议 ×0.7 或在文案后加"仅供参考，主席已明确不承诺路径"。
4. **禁止作为唯一依据**驱动闸门 / 仓位 / 评分。
5. **禁止给出确定性表述**："概率 >50% ⇒ 12 月加息"是错的，应写"市场定价约 X%，但主席未承诺"。

## 四、验收标准（引入时逐条勾）

- [ ] 展示处有"仅供参考 / 不确定性"标注
- [ ] 有明确数据时点（不是"当前"）
- [ ] 有来源说明（FedWatch / CME / 调查）
- [ ] 未进入决策链（grep `direction` / `gate` / `position` 确认无引用）
- [ ] 概率缺失时降级不报错（不能因外部接口挂了让整卡失败）
- [ ] 有单测覆盖：概率为 null / 极端值（0 或 100）时不崩溃

## 五、这条备忘什么时候可以关闭

当且仅当：系统确实引入了加息概率展示，且上面 6 条全部满足。
在那之前，**保持"不展示"比"展示一个会被误读的数字"更安全**。
