## 1. 为什么有这份文档

这个项目对**外围信号**的证伪非常严格：`flow_consec` 预登记 FAIL、战法 24 格 19 负被砍、
龙虎榜 PASS 但被**可执行性终验**拦住「按多头上线」、`sector_momentum` INSUFFICIENT……
**唯独核心的评分系统（三维动态权重 = 技术/资金/基本面，随 regime 切换）从没走过同样的程序。**

它是这个项目里唯一**免检**的假设，而下游一切都从它长出来：榜单页、买入闸门、观察池、
一页纸诊断、日报「今日主线」、模拟盘选股。外围证伪得再干净，也只是装饰物的质检。

★ 最直白的自我证据：`stock_diagnosis.SIGNAL_STATUS` 里，龙虎榜那行敢写
「预登记 **PASS**（T+5 −3.76%，P=0.0000）」，而**评分那行写的是口径声明，不是检验声明**。

**本文件要改变的就是这一点**：把评分放进和外围信号同一个程序里。

## 2. 问题定义

- **主问题（唯一）**：日批产出的**权威评分快照 Top50**，在此后可执行的持有期内，
  是否取得相对基准的**正向超额**？
- **伴生问题**：Top50 相对「可取价池内其余个股」是否有超额（分层的最粗形式）。
- **探索性**（不产生结论、不进决策）：分 regime、分数分位（Top10 vs 11–50）、
  维度贡献（`dimensions_json`）、行业与市值分布、`ranking_live` 全池分层。

⚠️ **这不是「买入信号检验」**：实测窗口 31 个快照日里 `signal='buy'` 占比 **恒为 0**
（系统长期处于**禁买**市况）。我们测的是「**防御/中性市里最不差的 50 只**是否好于基准」，
**不是**「这 50 只该不该买」。任何把结论读成后者都是误用。

## 4. 判据（**v1.1 冻结**；跑之前不得改）

### 4.1 主判据（唯一）
**T+5 超额（次日开盘建仓口径）**

```
对每个快照日 d（`ranking_history` 当日 rank_pos 1..50，等权）：
  入场 = d 之后第 1 个交易日开盘价（open）
  出场 = d 之后第 6 个交易日开盘价（open）
  组合收益 R_top(d)  = mean(open_exit / open_entry - 1)   ← 只统计两端口都有价的个股
  基准收益 R_bench(d) = **「可取价池」当日有价 A 股（0/3/6 开头）的等权**，
                        同一价格源、同两端口、**含当日 Top50**
  超额 e(d) = R_top(d) − R_bench(d)
```

- **基准命名（v1.1 改）**：v1.0 写的「池内 A 股等权」在实测后**更名为「可取价池等权」**——
  它是 `backtest_prices` 里**恰好有价的那部分股票**（941 只），只占评分宇宙（2224）的 **42%**
  ⇒ 它**不是**"被评分宇宙的平均"（缺价 1283 只无法测，大概率偏小票，方向未知）。
  ⇒ 结论措辞一律是「跑赢/跑输**可取价池**」；对评分宇宙的整体断言**超出本检验的效力**（§8-2）。
- **基准含当日 Top50（v1.1 钉死）**：Top50 占基准 50/941 ≈ 5.3%，把超额**轻微压低**
  （方向不利于 GO，保守）⇒ 可接受；「剔除 Top50 的池内其余」即 §4.3 伴生判据，两者并存。
- **口径写死的理由**：评分在 d 日**收盘后**才算完（日批 18:00）⇒ 只能在 d+1 建仓；
  项目已有硬教训「**收盘价入场几乎系统性高估**」（`event_executability_check` /
  `lhb_executability_check` 的 A 步）。故**主判据一律用开盘**，收盘口径**只作对照**另报。
- **建仓方式**：按快照日**独立建仓、持有 5 日**（不是每日再平衡）⇒ 成本只发生一次往返。

| 判定 | 条件 |
|---|---|
| **GO**（报告词汇 `PASS`） | 超额均值 ≥ **+0.60pt** ｜ 聚类 bootstrap **单侧 P ≤ 0.05** ｜ T+10 同向（均值 > 0）｜ **不重叠子样本方向一致**（§4.4-3） |
| **KILL**（报告词汇 `FAIL`） | **① 均值 ≤ 0 且 bootstrap 95% 上界 ≤ +0.30pt**（"乐观估计也不具经济意义"）**或 ② 均值显著为负**（P(μ<0) ≤ 0.05）；且**不重叠子样本方向一致** |
| **PARTIAL** | 两者都不是 |
| **INSUFFICIENT** | 样本闸不满足 |

- **★ v1.1 修掉的 KILL bug**：v1.0 的 KILL =「均值 ≤ 0 且 P ≥ 0.20」——
  ①「均值显著为负」（最坏的发现）会既非 KILL 也非 GO ⇒ 落 PARTIAL（把最坏降级）；
  ② 真效应 = 0 时点估计约一半概率 ≤ 0 ⇒ KILL 有约 50% 机会**凭掷硬币触发**，
  而它要写进 `SIGNAL_STATUS`，不能这么轻易。v1.1 改成**等效性检验式**（见上）：
  真零分多半落 PARTIAL（"没证据说有、也没把握说没有"），真负分照样 KILL。
- **+0.60pt 的来处**：介于本项目两条既有门槛之间 —— LHB 可执行性 +1.00pt（事件类、
  次日跳空大），`shadow_rank` +0.30pt（配对、同池）；Top50 是**日度组合**且 5 日持有 ⇒
  取 +0.60pt（≈ 48 个不重叠周期/年；扣 0.30% 往返后净 ≈ +0.30pt/期）。**三个持有期用同一
  绝对门槛**（对更长持有期更严 ⇒ 保守，v1.1 钉死）。
- **统计细节（v1.1 钉死）**：bootstrap = **按快照日整日重抽样**（B=10000，**seed=20261011**，
  每个持有期重置同一 seed）⇒ 单侧 **P(μ>0) = bootstrap 均值 ≤ 0 的比例**；95% 上界 =
  bootstrap 均值的 **95 分位**；P(μ<0) = bootstrap 均值 ≥ 0 的比例。全为**单侧**检验。
- **样本闸（先于判据生效）**：主判据需 **≥ 20 个到期快照日 且 ≥ 800 观测**；
  不满足一律 `INSUFFICIENT` —— **不解释、不改门槛、不放宽**。
  （观测数是覆盖纪律；**有效样本量 = 天数** —— 见 §8-1 重叠窗口。）

### 4.2 次判据（2 个，仅作佐证；Bonferroni α = 0.025）
- T+10 超额（同口径；**现 21 天，已达标**）；
- T+20 超额（同口径）—— **现仅 11 天 < 20 ⇒ 本轮只报 `INSUFFICIENT` 与计数，不打印任何收益数字**
  （避免拿欠功效数字当谈资；达 20 日后由月度复检自动判）。
- 每次报告必须**同时**列出 5/10/20 三个持有期的**判定状态**（**禁止只报最好看的那个**）。

### 4.3 伴生判据（非独立，不单独产生 GO/KILL）
Top50 − **剔除 Top50 的可取价池**其余（等权）的 T+5 差；看「相对强弱方向」，样本不足不作结论。

### 4.4 敏感性（必报，不改变主判定）
1. **扣成本**：往返 **0.30%**（照 LHB 口径）后的净超额；
2. **剔除买不到**：入场日开盘 ≥ 快照日收盘 ×（1 + `backtest.engine._limit_pct(code) − 0.002`）
   （**v1.1 改**：v1.0 的固定 ×1.095 是 10cm 假设，对 20cm 板会把普通高开误判为"买不到"；
   板幅口径与 `limit_stats` 同源）；
3. **不重叠子样本**：到期快照日每隔 5 个取 1 个（T+5 ⇒ ~5 个独立窗口）；其**均值方向**
   必须与主判据一致（v1.1 升级：只作方向核验，不做显著性——窗口太少，算不出 P）；
4. **指数对照**：对 `sh000300`、`sh000852` 的超额（**v1.1**：`sh000852` 因「可取价池 ≠ 评分
   宇宙」升为**次级参照**，仍不计入多重比较）；
5. **早期窗口交叉验证**：窗口收在 **2026-09-24 之前**，用本地 `data/zzshare_daily.db`
   （含 `is_st`/`is_paused`、5569 只）剔 ST/停牌后复跑 —— 只作敏感性，两库复权口径不同
   （宁少勿混，同 LHB 教训）。

## 5. 决策后果（**判据先于结果定义**）

报告词汇映射（`edge_verify` 契约）：**GO→`PASS`、KILL→`FAIL`、其余 `PARTIAL`/`INSUFFICIENT`**。

| 结果 | 必须做什么 | **禁止**做什么 |
|---|---|---|
| **GO** | 在 `stock_diagnosis.SIGNAL_STATUS` 给评分补上与龙虎榜同级的检验结论（含效应量/P/样本/市况限定）；可另立**独立的**权重变更预登记 | 直接改权重/衰减/闸门参数 |
| **KILL** | 把 `SIGNAL_STATUS` 里评分那行改成如实披露（「未通过预测力检验：T+5 超额 …，P=…」+ 市况限定）；产品重心提案转向**已被验证的空头/回避侧**（LHB 大额净卖、出货标签） | 自动改任何生产参数；删掉评分（它仍是**相对排序**的展示工具） |
| **PARTIAL** | 记录 + 等 T+20 与 `ranking_live` 分层成熟后复判 | 选择性引用其中好看的分组 |
| **INSUFFICIENT** | 只更新到期日计数；由 `edge_verify` 月度带跑，到点自动复判 | 因"看起来没戏/太有戏"提前下结论 |

★ 与 `shadow_rank_edge_check` 同规矩：**本节只出证据，任何生产参数变更须另行预登记并经人确认。**

## 8. 已知局限（如实，不得粉饰）

1. **重叠窗口 ⇒ 有效样本 ≪ 名义天数**：相邻快照日的 T+5 窗口共享 4/5 天，25 个到期日的
   信息量约等于 **~5 个不重叠窗口** ⇒ 后果不对称：GO 难触发（防假阳，是好事）、KILL 靠
   §4 的 CI 上界条款防"低功效误杀"；不重叠子样本只作方向核验；
2. ★ **基准是「可取价池」（941 只），只占评分宇宙（2224）的 42%** ⇒ 结论措辞只能是
   「跑赢/跑输可取价池」；缺价 1283 只（大概率偏小票）无法测，**对评分宇宙的整体断言超出本检验效力**；
3. **只有 Top50** ⇒ 检验「分数越高越好」的**最强形式（分层单调性）做不了**（`ranking_live` 成熟后补）；
4. **窗口 31 天、且全程无 offensive 市况** ⇒ 结论**只在「中性/偏空/防御」市况内成立**；
5. **`signal='buy'` 恒 0** ⇒ 测的不是买入信号（§2）；
6. **价格池 941 只、非全市场，且无法剔 ST/停牌**（缺列）⇒ 脚本必须**逐日打印 Top50 落在池外的只数**
   （实测 T+5 两端缺价 0/1250 ✓）；
7. **复权口径未核**（短窗口 5~20 日可降低分红影响，但不消除）；
8. **主判未扣成本**（净额另报）；
9. **快照数据完整性**：`price` 已抽查 = 当日收盘，且日批有包新鲜度闸 ⇒ 脚本仍打印逐日快照行数
   与价格覆盖率，异常日（行数 ≠ 50）必须显式暴露；
10. regime 分层、行业/市值、维度贡献全部**只作探索**，**不产生结论、不进决策**。

## 11. 衍生预登记：**分层单调性 / 回避侧**（2026-10-11 立项；**数据未成熟，未跑**）

【动机】主判据 KILL 只回答了「顶部跑输平均」；§5 的 KILL 后果要求"重心转向回避侧" ⇒
  自然的下一个问题：**分数在"避开谁"上有没有信息？**（低分组是否系统性跑输 ⇒ 评分作为
  **回避器**的价值。）本节在其**任何数字被看过之前**冻结判据（与 §4 同纪律；
  当前数据面也答不了这个问题 —— 见下）。

【数据面（2026-10-11 实测）】`ranking_history` 只有 Top50 ✗；`ranking_live`（每日 1000 条，
  `rank_pos` 1..1000，= 评分宇宙 2224 的**前 45%**）自 2026-09-28 起留痕 ⇒ **今天只有 5 个
  快照日，无法检验**；随日批自然累积，约 **2026-11 中旬**达 20 个到期日。
  ⚠️ 语义边界：可测的"低分组"最低只到**第 1000 名**，评分宇宙的**后 1224 名没有留痕** ⇒
  本检验测的是「**评分池内相对低位**」的回避价值，**不是**"全市场最差的票"（那需要扩留痕，另行立项）。

【判据（冻结；改判据须在此新开一节并注明日期）】
  · **分层**：`ranking_live` 的 `rank_pos` 按 **100 名一档分 10 档**（1-100 … 901-1000）；
  · **口径**：与 §4 完全同源 —— 次日开盘入 / 第 N+1 日开盘出、基准=可取价池等权（同源同步）、
    按快照日聚类 bootstrap（B=10000、seed=20261011）、单侧检验；N=5 主、N=10 佐证；
  · **主判据（回避价值）**：最低档（901-1000）T+5 超额 **≤ −0.60pt** 且 单侧 **P(μ<0) ≤ 0.05**
    且 不重叠子样本方向一致 ⇒ 「**回避侧有信息**」（报告词汇 PASS）；
  · **佐证（单调性）**：10 档超额与档位的 Spearman ρ ≤ −0.4，或 ≥7/10 档严格递减；
  · **反向保护**：若最低档超额 ≥ 0（低分并不更差）⇒ 记录"**回避侧无信息**"，评分仅剩展示
    价值 —— **同样不自动改任何生产参数**；
  · **样本闸**：≥20 到期日 且每档 ≥400 观测，否则 INSUFFICIENT（分档缺失行如实打印）；
  · **实现**：扩 `score_edge_check.py --source=live`（数据源换成 `ranking_live`，骨架复用），
    达样本门槛后接进 `edge_verify` 月度复检 —— **在数据达标之前不实现、不看任何数字**。
  · **后果**：回避侧成立 ⇒ `SIGNAL_STATUS` 补"评分可作回避参考（低分≠安全名单外≠安全）"；
    不成立 ⇒ 维持 FAIL 披露原样。**两者都不改生产参数。**
