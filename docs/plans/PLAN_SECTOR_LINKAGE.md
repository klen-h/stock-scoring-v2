## 0. 动机与现状（诚实披露）

- 评分排行榜的预登记检验**已 FAIL（KILL）**：`PLAN_SCORE_EDGE.md` §4 v1.1 / §9 ——
  快照 Top50 此后 T+5 **跑输可取价池等权 −1.43pt**、T+10 −2.21pt（25 到期日 / 1250 观测）。
- 本机制是**对该 FAIL 的一次结构性修复尝试**：不是调权重、不是调阈值，而是**在排名层加一道
  「板块资格」门**——只有处于强势行业的个股才允许进入 Top50。
- ★★ **两条反面证据必须先读**（都是本项目自己的实测，不是文献）：
  1. **行业动量无预测力**（E2 期研究：E2 命中期是普涨而非轮动，"买宽基即可"）；
  2. `scripts/sector_momentum_edge_check.py` 的板块动量检验**至今 INSUFFICIENT**（序列 2026-08-21 起）。
  ⇒ **本机制很可能不成立**。允许被证伪是它能上线的前提；KILL 则配置定案 `off`。
- ★★ **禁止事项**：不得用"回查胜率变好了"来反推窗口/TopK/阈值。判据在本文件冻结，
  回查结果只用于**判定 GO/KILL**，不用于调参。

## 1. 板块走势的评估依据与判定标准（冻结）

| 项 | 口径 |
|---|---|
| 行业维度 | `stock_industry.main_industry`（新浪 49 类，**唯一可与个股精确关联的 taxonomy**） |
| 为什么不用 zzshare 板块 | `plate_daily_zz` 是 zzshare 104 粗分，与新浪 49 类**仅 4 个同名**（塑料制品/房地产/医疗器械/仪器仪表）⇒ 名称匹配会产出误导性"板块内 0 只" ⇒ **不桥接** |
| 行业指数构造 | 行业内成分股**日收益等权均值**（当日无有效价/停牌股剔出分母；**缺失 ≠ 0，缺失 ≠ 满足**）；再复利累计 |
| 价源（生产） | `backtest_prices`（989 只池、日批更新，与回查价源同源）。⚠️ 池偏差：以主板为主、含战法/ETF 池，**不代表全市场**，如实披露 |
| 价源（历史回放） | 本机 `data/zzshare_daily.db`（6123 只 / 2005 起，零 egress）+ `_code_industry` 映射 ⇒ 可回测 21 年 |
| 主窗口 | **`ret5`** = 最近 **5 个交易日**的复利累计涨幅（%） |
| 强势判定 | `ret5 > 0` **且** 横截面分位 ≥ 70%（= 49 个行业里排前 30%，约 Top 15） |
| 噪声剔除 | 成分股（有当日价）< **5** 只的行业**不参评**（不占分位名额） |
| 普涨守卫 | 连续 **3** 个交易日「池内上涨家数占比 ≥ **70%**」⇒ 当日**过滤失效**（E2 期实证：普涨非轮动，行业选择无增量） |
| 数据不足 | 有效交易日 < 6（算不出 ret5）或行业数 < 10 ⇒ **过滤失效** |

> 分位口径固定为「在当日**参评行业**内按 ret5 降序取前 30%（向上取整）」，同时要求 ret5 > 0。
> 这样普跌日会自然产出 0 个强势行业，由 §3 的 fail-open 接管。

## 2. 强势板块与个股的关联规则（冻结）

1. 个股 → 行业：`app/industry_map.py::get_industry_map()`（1h 缓存，月级重建）精确匹配
   `code → main_industry`；**不做名称模糊匹配、不做多级行业链回退**。
2. 命中规则：个股行业 ∈ 当日强势行业集合 ⇒ 有排名资格。
3. **映射缺失**（`stock_industry` 无该股）：**保留**其排名资格（fail-open），
   但在返回的 `sector_filter.unmapped_n` 里**如实计数**——"查不到归属"不等于"不属于强势板块"。
4. 板块内个股不额外加权/不改变 `total_score`：本机制**只决定"谁能进榜"**，不改分数与排序逻辑。

## 3. 排除逻辑：触发条件与边界（冻结）

| 情形 | 行为 | 返回标记 |
|---|---|---|
| `SECTOR_LINKAGE_MODE=off` | 不过滤 | `mode=off` |
| 当日强势行业 **≥1** 且普涨守卫未触发 | **过滤生效**：从全量排序中按原顺序取强势行业内个股补满 `limit` | `active=true, strong_n=N, excluded_n=K, backfilled_n=M` |
| 当日强势行业 **= 0**（普跌/分位不满足） | **放行**（不产出空榜） | `active=false, reason=no_strong` |
| 普涨守卫触发 | **放行** | `active=false, reason=bull_market` |
| 板块强度表当日无行 / 读库失败 | **放行**（fail-open） | `active=false, reason=unavailable` |
| 映射缺失个股 | 保留 | `unmapped_n` 计数 |
| 强势行业内个股不足 `limit` | 用强势行业内所有合格个股 + 其余按原顺序补足 | `short=true` |

- **为什么普跌日放行而不是空榜**：`ranking_history` / 决策简报 / 观察池 / 工作台都依赖 Top50；
  空榜会让整条下游断粮，而"防御市不买"已由闸门（`trade_gate`）承担，不需要榜单为空来表达。
- 所有"失效"都在返回结构里**显式打标**，不允许静默。

## 4. 对现有排行榜计算流程的影响范围（冻结）

- **只加在"排名可见性"层**，三路统一：
  1. `GET /api/score/batch/top`（在线两阶段 / 全量精算榜命中路径）
  2. 日批 `task_score_snapshot`（快照写入 `ranking_history`）
  3. 调度器兜底（`flash/scheduler.py` 的 `score_top` 调用）
- **`ranking_history` 原版一字不动**：过滤版写在**平行表 `ranking_history_sector`**
  ⇒ `mainline`（行业扎堆）、观察池、既有回查脚本、日报全部零影响。
- **不动**：评分引擎、`score_single` 详情页、`_pool_quality_filter`（质量过滤语义不混入板块语义）、
  战法池、模拟盘、`trade_gate`。
- 开关：`SECTOR_LINKAGE_MODE=off|shadow|on`（默认 **shadow**），登记进 `app/env_check.py`。
  - `shadow`：照常算、照常落 `ranking_history_sector`，**前端榜单仍展示原版**；
  - `on`：榜单返回过滤版 + 前端本地榜同步过滤；
  - `off`：完全不算（连强度表都不写）。
- 前端：`useFrontendScoring.js` 在 `on` 模式下读取后端下发的强势行业清单同步过滤
  （避免"后端过滤、前端不过滤"的口径漂移）；`ScoreRank.vue` 与工作台加一行定位说明 + 排除/递补数量。

## 5. 验证链（顺序不可颠倒）

1. **判据冻结**（本文件）→ 2. 历史回放（判据预测力）→ 3. 快照 A/B → 4. 影子并行 → 5. 前瞻复判。

### 5.1 历史回放 A：行业强度本身的预测力（判据层）
- 数据：`zzshare_daily.db` 21 年、全市场（含 ST/科创/北交）。
- 事件：某日行业 `ret5` 进入前 30% 且 > 0。
- 检验：该行业未来 5 日等权收益 − **同日全部行业等权** ≥ 0？按**交易日**聚类 bootstrap（B=10000）。
- 独立单位 = 交易日（同日多行业共享同一段行情，横截面相关未被消除）。
- 样本闸：≥ **250 个交易日**（21 年内应轻松满足）；不足 ⇒ INSUFFICIENT。

### 5.2 历史回放 B：快照 A/B（榜单层）
- 样本：既有 31 个快照日（`ranking_history`），价格取 `backtest_prices`。
- 对照：过滤版 Top50 vs 原版 Top50，**T+5 / T+10 超额（vs 可取价池等权）**。
- 引擎口径复用 `scripts/score_edge_check.py`（含一字板剔除、可取价池）。

### 5.3 判定线（预冻结）
- **GO（=PASS）**：`过滤版超额 − 原版超额` 的 T+5 配对 bootstrap **95%CI 下界 > 0** 且点估计 ≥ **+1.0pt**，
  且 T+10 同号、分年前后半段同号。
- **KILL（=FAIL）**：95%CI **上界 < 0**（双条件式，参照 `flow_consec` 教训：单条件过松会误杀）。
- **样本闸**：≥ **20 个到期快照日**（31 个里剔除未到期/无价）。不足 ⇒ **INSUFFICIENT**，只报描述统计。
- 30 个快照日之前的结论一律标"检验力有限"，**不得据此切 `on`**。

### 5.4 注册
- 脚本 `scripts/sector_linkage_edge_check.py` 注册进 `app/edge_verify.SCRIPTS`（月度复核，`--json` 契约）。
- `SECTOR_LINKAGE_MODE` 切 `on` 需 **GO + 用户拍板** 两个条件。

## 6. 已知局限（不粉饰）
- `backtest_prices` 池 989 只、以主板为主 ⇒ 行业指数**有偏**（小盘/科创/北交覆盖不足）。
- 行业分类是**新浪 49 类**粗分，"板块"颗粒度比市场习惯的 104 细分粗。
- 快照样本只有 31 日、且区间内 `signal='buy'` 恒 0（禁买市）⇒ 结论只能限定在该窗口。
- 本机制**不是交易信号**，榜单定位仍是"候选池 + 变化监测，非买点清单"。
