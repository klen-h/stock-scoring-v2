## 表：`stock_facts_wide`

### A. 标识与基础行情（源：market_snapshot 收盘定稿 + stock_industry）
| 列 | 类型 | 说明 |
|---|---|---|
| date | TEXT | 交易日（主键之一；= 数据所属日，非写入日） |
| code | TEXT | 6 位码（主键之一） |
| name | TEXT | 名称 |
| industry | TEXT | 行业（新浪 49 类；"其它行业"如实保留） |
| board | TEXT | 主板/创业板/科创板/北交所（由代码前缀派生） |
| close | REAL | 收盘价 |
| chg_pct | REAL | 当日涨跌% |

| turnover_pct | REAL | 换手率% |
| vol_ratio | REAL | 量比 |
| ret5 / ret20 | REAL | 5/20 日收益%（宽表内自算，滚动窗口） |
| dist_from_60d_high | REAL | 距 60 日高点%（=高位/回撤事实） |

### B. 评分（展示工具，徽章：**FAIL/KILL 2026-10-11**；源：ranking_live）
| 列 | 说明 |

### C. 主力行为（事实标签；徽章：mult=off 无消费方；源：mainforce_state）

### D. 买入闸门（状态展示，非买入信号；源：gate_snapshot_history.payload 按票拆）
gate_ready（0-3）· gate_missing（缺什么，TEXT）· gate_pos_label（建议仓位档=状态展示）

### E. 风险/回避（徽章：**PASS-回避侧**；源：lhb_history 近 10 日）
lhb_big_net_sell（0/1：最近一次上榜为大额净卖）· lhb_latest_date（最近上榜日，过期即 0）

### F. 形态（徽章：**预登记中**，前瞻样本未到期；源：pattern_scan_daily）
pattern_hit（0/1：缩量启动当日命中）

### G. 板块（徽章：**影子期 PARTIAL**；源：sector_strength_daily）
sector_ret5（行业 5 日收益%）· sector_top30（0/1：强势=前30%∧>0∧成员≥5）·
sector_pass_filter（0/1：影子过滤版该股是否保留——平行口径，不动主榜）

### H. 防御组（徽章：**H2' 影子中**）
defensive_group（0/1：银行∪高股息代理∪低波成员——与防御影子榜同清单）

### I. 元信息（随表下发，接口层注入）
每列的检验徽章不落库（前端由 `/api/score/diag` 同款 SIGNAL_STATUS 唯一事实源渲染）；
表级 `as_of`（各行数据所属日的最小值）+ 行级 date 已足够时点诚实。

## 覆盖范围与生成
- **主集 = 当日精算榜前 1000**（ranking_live 全集；评分宇宙 2136，榜外 1136 只无 B 列——
  行业/行情/主力等事实列照有，score 列为 NULL，**NULL=不在榜，≠0**）。
- 生成：日批新任务 `task_stock_facts_wide`（排在 rank_live/sector_linkage/gate_snapshot 之后、
  daily_report 之前；失败不拖垮整批）；幂等按日覆盖；预估 ~1000-2136 行 × ~30 列。
- egress：全部读既有日批产物表（当日行），无新增外呼；宽表写入 <1MB/日。

## 明确不进宽表的（红线示例）
- 任何"综合选股分/加权分"（=新信号，须预登记）；
- 消息分（FAIL，且为独立展示维度）；
- 盘中实时价（接口层由腾讯缓存另行补，标 from_snapshot）；
- 战法信号（6 战法全部不可交易；如需进表须逐个带"不可交易"徽章——v0 不进）。
