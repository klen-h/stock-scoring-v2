## 1. 假设

**H1（主）**：由生产扫描（默认参数：启动涨幅 ≥3.0%、缩量 ≤0.7、调整 20 日 / 基准 60 日、
放量 ≥2.0×、突破、冷却 10 日）产出的「缩量启动」信号，在 **T+10** 上相对**同资格无条件基准**
有**正向净超额**（已扣双边成本 0.30%）。

## 2. 判据（冻结）

| 项 | 值 |
|---|---|
| 主窗口 | **T+10**（T+1 开盘建仓 → T+10 收盘） |
| 收益口径 | 毛收益 − **0.30%**（双边：佣金+印花税+滑点，与 `shrink_rebound_live` 同源） |
| 基准 | **同资格无条件**：同池、同入场口径、取样起始 ≥ pullback+base 根历史（防新股连板污染） |
| 可执行性 | 剔 T+1 开盘即涨停（买不进）、剔 T+1 停牌；不合格样本剔除并计数 |
| 显著性 | **按信号日聚类** bootstrap（seed=20261015，B=4000），单侧 P(μ ≤ 基准) |
| **GO（PASS）** | 净超额 ≥ **+1.00pp** ∧ 聚类单侧 **P ≤ 0.05** ∧ **T+20 同向**（净超额 > 0） |
| **KILL（FAIL）** | **等效性式**（防"低功效误杀"）：净超额 95% 上界 ≤ **+0.30pp**，**或** 显著为负（P(μ ≥ 基准) ≤ 0.05） |
| 其余 | 报 `PARTIAL`（方向对但未达线）/ `INSUFFICIENT`（样本闸未达） |
| 样本闸 | **≥ 20 个独立信号日 ∧ ≥ 120 个 T+10 到期观测** |
| 观测单位 | 一只票的一个信号 = 一个观测；**簇 = 信号日**（同日多票共享市况 ⇒ 不可当日独立样本） |

## 3. 降级规则（**预冻结**，防"偷偷挑数据"）

1. **60 个交易日后**仍未达样本闸 ⇒ 允许把 **T+20** 的到期观测**并入观测计数**
   （同一信号的两个窗口**只增加观测、不增加簇**）——提高样本量，**不改变判据本身**；
2. **120 个交易日后**仍不达闸 ⇒ **永久 `INSUFFICIENT`，归档为"样本不足的边际"**；
   ⚠️ **不得放宽形态参数再试**（那等于换假设挑数据）；要换假设须**另立 v2.0 并重新前瞻**。

## 4. 数据与口径

- **信号来源**：`pattern_scan_daily`（日批落库，`date ≥ 2026-10-15`）；
- **前视价格**：`backtest_prices`（995 只回测池、每日更新）；逐股回填 ⇒ 信号日需
  等 `T+10` 的 bar 就位后才计入观测（未到期 = 不计入，也不计入 n）；
- **全链路只读 Postgres**（不依赖本地 `zzshare_daily.db` / 大文件）⇒ **可安全注册月度复核**
  （对照教训：`mf_edge_check` 与两个 LHB 脚本因依赖本地库而**刻意不注册**，见 `app/edge_verify.py`）。

## 5. 已知局限（先写下来，防事后找借口）

1. **样本量小**：回测池 995 只 + 默认参数 ⇒ 日均命中约 0~2 只 ⇒ 达闸门预计 **1~3 个月**（含无信号日）；
2. **一字板剔除用近似**（`backtest_prices` 无交易所涨停价列，用 `open/prev_close ≥ +9.8%` 判，
   未区分 20cm 板块）⇒ 与 B 项的精确口径略有差；
3. **窗口单一市况风险**：若前瞻期全为单边市，结论只在该市况内成立（同 `score_edge_check` 的教训）；
4. 未计冲击成本/容量约束。
