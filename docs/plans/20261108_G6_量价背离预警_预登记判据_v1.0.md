# G6 量价背离预警 · 预登记判据 v1.0（2026-11-08 冻结）

> ⚠️ **预登记纪律**（同 C5 形态检验）：本判据**冻结后只对冻结日之后的前瞻样本生效**；
> 跑数/看结果之前不得回头改任何阈值；GO 且用户拍板才进 `SIGNAL_STATUS`。
> 本文只冻结判据与实现规格，**实现未开始**。

## 一、信号定义（两类背离，盯"自己"口径）

作用对象：**自选股 + 真实持仓 + 模拟仓**（`gate_watch`/`user_portfolio`/`paper_positions` 池），
盘中与收盘各判一次；这是"替你盯自己"的假突破特征标注（专业盯盘标准第五类），**纯观察器**。

| # | 背离 | 判据（**全部冻结，改动须新开 v1.1 留痕**） | 为什么是假突破特征 |
|---|---|---|---|
| ① | **缩量新高** | 收盘价（盘中=现价）创 **60 日新高**（含当日，用 klineDB 日线本地判）**且** `volume_ratio ≤ 0.7` | 无量新高 = 追涨盘未跟进，破位即多杀多 |
| ② | **放量滞涨** | `volume_ratio ≥ 2.0` **且** `\|change_pct\| ≤ 1.0%` **且** 现价处于 **60 日区间 ≥80% 分位**（高位才有滞涨意义；低位放量是启动不是背离） | 高位放量不涨 = 出货特征（600150 教训的泛化） |

数据源：**零新增外呼**——量比（腾讯快照 [49] 已解析）、创新高/分位（klineDB 日线本地算）。

## 二、实现规格

- 载体：新观察器 `app.divergence_watch`，日批 + 盘中（随既有 60s 快照循环顺手判，不新增轮询）；
- 落库：`divergence_watch(date, code, kind, snapshot_json)` 按日 append；
- 展示：自选/持仓列表行内 🔴 标注 + 悬停判据原文；**不入评分/闸门/仓位/模拟盘**（R2）；
- 触发只读既有表与本地包 ⇒ **egress 增量 = 0**。

## 三、检验判据（攒样本后跑，样本闸 ≥20 个标注日）

- 主指标：标注后 **T+5 相对收益**（vs 同期可取价池均权）≤ **-1.0pp** ⇒ 预警有信息（背离后确实更差）；
- T+10 同向；按标注日聚类单侧 P ≤ 0.05；
- **KILL**：T+5 相对收益 > 0 且 95% CI 跨 0（等效性式——预警无信息则撤标注）；
- 检验引擎复用 `score_edge_check` 框架；**两背离分开统计**（混池会互相对冲，同 C6 游资/机构教训）。

## 四、明确不做

- 不做"背离 = 卖出"式建议（R2：判据未检验前只是标注）；
- 不回填历史样本（无逐日量比历史快照，硬造=美化）；
- 60 分钟级背离（无分钟数据源，随 G9 一并出局）。
