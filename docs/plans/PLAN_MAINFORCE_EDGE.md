## 2. 问题定义

- **主假设（唯一）**：日批口径下，**主力阶段 = 吸筹（accumulation）且买入闸门三绿
  （`trade_gate.summarize(evaluate(code, mf)) == 3`）**的个股，在此后可执行的持有期内，
  取得相对基准的**正向超额**。
- ⚠️ 三绿本身**内嵌市况条件**（gate 含"市况允许/不追高"项）⇒ 本检验测的就是
  **生产闸门的完整输出**，不做任何"理论上更好的"变体。
- **探索性**（不产生结论、不进决策）：吸筹-only / 三绿-only 分解、phase 对照组、
  flow5 分层、市况分层。

## 4. 判据（**v1.0 冻结**；跑之前不得改）

### 4.1 选股条件（从生产代码取，**禁止重写实现**）
对每个判定日 d（= 日批产出的当天）：
```
宇宙   = mainforce_state(d) 中 phase == 'accumulation' 的个股
         ∧ _is_stock_code(code) ∧ _pool_quality_filter（与 /batch/top 批量池同款）
条件   = trade_gate.summarize(trade_gate.evaluate(code, mf=d日落库数据)) 的 ready == 3
```
回填/重算一律**调用生产函数**（`app.mainforce.state` / `app.mainforce.trade_gate`），
禁止另写近似实现（检验对象 = 生产定义本身）。

### 4.2 主判据：T+5 超额（次日开盘建仓口径）—— **引擎复用 `score_edge_check.py`**
```
入场 = d 之后第 1 个交易日开盘价；出场 = d 之后第 6 个交易日开盘价
组合收益 = 当日入选个股等权（只计两端口都有价者）
基准     = 可取价池（当日有价 0/3/6 A 股）等权，同两端口、含当日入选
超额 e(d) = 组合 − 基准
```
- ★ **一字板剔除（与评分检验的差异点，冻结）**：入场开盘价 = 当日板幅口径涨停价 ⇒
  该票**该日剔除并计数**。理由：吸筹+三绿恰是"次日一字"的高发形态，不剔除会
  **系统性高估**（LHB 可执行性检验的既有教训）。剔除率 > 30% ⇒ 结果强制带警告行。
- bootstrap：按判定日整日重抽样，B=10000，**seed=20261011**（与评分检验同 seed 纪律）。

| 判定 | 条件 |
|---|---|
| **GO**（`PASS`） | 超额均值 ≥ **+0.60pt** ｜ 单侧 P ≤ 0.05 ｜ T+10 同向（均值 > 0）｜ 不重叠子样本方向一致 |
| **KILL**（`FAIL`） | ① 均值 ≤ 0 且 bootstrap 95% 上界 ≤ **+0.30pt**（等效性式，防"真零掷硬币"）**或** ② 均值显著为负（P(μ<0) ≤ 0.05）；且子样本方向一致 |
| **PARTIAL** | 两者都不是 |
| **INSUFFICIENT** | 样本闸不满足（不解释、不改门槛、不放宽） |

- **+0.60 / +0.30 线沿用评分检验**（同一绝对门槛对 T+10 更严 ⇒ 保守）；独立建仓、持有 5 日。
- **样本闸**：≥ **20 个判定日** 且 ≥ **120 观测**（有效样本量 = 天数，重叠窗口同 §8-1 处理）。

### 4.3 次判据（仅佐证；Bonferroni α = 0.025）
- T+10 超额（同引擎同门槛）。每次报告必须**同时**列出 T+5/T+10 两个判定状态
  （**禁止只报最好看的**）。

### 4.4 ★ **降级规则（预先冻结，自动切换，防事后挑假设）**
- 主样本闸在**登记后 90 个交易日**内仍不满足 ⇒ 自动切换主假设为 **H2：吸筹 ∧ ready ≥ 2**

- H2 也长期不满足 ⇒ 继续**前瞻累积**，报告 `INSUFFICIENT`——**不得再换第三个假设**

- 切换时在 §9 只记录**切换日期与原因（样本计数）**；**切换前禁止打印任何收益数字**

## 11. **T+20 扩展**（判据 v1.0，冻结于 2026-10-14 —— **先冻结、后跑**）

> 背景：§9 首跑 T+5 / T+10 双 `PARTIAL`（T+10 点估计 +1.14pt 但子样本转负）。T+20 是
> 「更长持有期会不会兑现」的自然追问；回填数据（426 日）已支持，**无需新数据**。
> ★ 本节**不改** §4 的任何既有条款与 §9 的既有判定（T+5/T+10 的 α 与结论保持原样）；
> 只登记第三个持有期的口径。

1. **同口径**（完全沿用 §4.2，不做任何调整）：入场 = d 之后第 1 个交易日**开盘**；
   出场 = d 之后第 **21** 个交易日开盘（持有 20 个交易日）；当日等权；基准 = 可取价池
   等权、同两端口、含当日入选；**一字板剔除**进主口径；bootstrap = 按判定日整日重抽样
   （B=10000，**seed=20261011**，与 5/10 同一纪律）。
2. **多重性（冻结）**：新增第三个持有期 ⇒ 检验族共 3 个（主 T+5 + 次 T+10 + 次 T+20）
   ⇒ **T+20 单侧 P 门槛 α = 0.05/3 ≈ 0.0167**（Bonferroni）。T+10 首跑用的 α=0.025
   **不改**（它按当时冻结口径出结论；此处只声明族内新增）。
3. **判定（冻结）**：
   - **GO**：T+20 均值 ≥ **+0.60pt**（与 5/10 同门槛，对长持有期更严 ⇒ 保守）∧
     单侧 P ≤ **0.0167** ∧ **T+10 均值 > 0**（长周期确认）∧ 不重叠子样本（**步长 20**）
     方向一致；
   - **KILL**：均值 ≤ 0 且 95% 上界 ≤ **+0.30pt**，或 P(μ<0) ≤ 0.0167（+方向一致）；
   - **PARTIAL** 其余；**INSUFFICIENT**：样本闸（≥20 判定日 ∧ ≥120 观测）不满足。
4. **欠功效纪律**（借评分检验先例，冻结）：T+20 若未达样本闸 ⇒ **只报 INSUFFICIENT
   与计数，不打印任何收益数字**（欠功效数字不进报告）。
5. 报告纪律：三个持有期（T+5/T+10/T+20）**判定状态全报**，禁止只报最好看的那个。
